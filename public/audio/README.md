# Recorded words

Generated by `npm run make:audio`, never edited by hand.

`clips.json` lists the ids of the clips actually present. The app plays a
recording only for a string listed there and speaks everything else with the
device voice, so an empty list — which is what ships until the clips are
generated — simply means every word is spoken by the iPad.

The `.m4a` files are deliberately not committed: they are large, and they are
reproducible from `words.ts` at any time. Run the generator before deploying
if you want them in the build.
